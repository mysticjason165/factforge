✳ FactForge · Article Editor

Edit longer articles, 3–5 custom photos, and YouTube links. Export one JSON file — no coding needed.

1. Open your existing files

Open this file using a local web server or on your website. If nothing loads automatically, choose your two repository files below. Everything stays in your browser until you download the JSON.

Tip: In a terminal, run python -m http.server 8000 in your FactForge folder and open http://localhost:8000/EDIT-POSTS.html.

2. Edit an article

Article sections

Write a descriptive heading and at least two substantial paragraphs for each section. Separate paragraphs with one blank line.

Leave images blank to use four starter Unsplash photos automatically. Use images you are allowed to publish.

Choose a post and start writing. Download when you are ready to publish.

3. Publish to FactForge

After downloading, replace post-content.json in the root of your GitHub repository. Your existing article pages will display the new text, photos, and video link automatically — no editing 125 separate HTML files.

Important: Your update is not live until you upload your downloaded JSON file to GitHub. Drafts with fewer than approximately 2,000 total words will correctly display a shorter reading time.
