Give the Evening a Clear Stopping Point

FactForge · 1 min read

An evening can stretch because every activity leads into another. One more message becomes a video, then a search, then a task you suddenly remember. A stopping routine can help define when optional activity ends.

Choose a few quiet steps you can repeat without much preparation. Put tomorrow's reminders in one place, finish necessary chores, and reduce stimulating screen activity near bedtime. The NHLBI recommends allowing quiet time before sleep and keeping sleep times reasonably consistent.

Avoid making the routine so long that you postpone it. A short version is useful when the day runs late. If a thought about tomorrow appears, write it down instead of reopening the whole workday. The routine is an invitation to settle, not a test you must pass to deserve rest. Continued difficulty sleeping is a reason to seek appropriate help.
