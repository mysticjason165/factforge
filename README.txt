FACTFORGE — DISCOVERY MAGAZINE REDESIGN

1. Extract the ZIP.
2. Replace index.html, style.css and script.js in your existing FactForge repository.
3. Keep your existing posts folder, including posts/fact1.html. That article was not supplied and is not included here.
4. Commit the changes and allow your existing GitHub Pages deployment to finish.

Open index.html locally to preview. Images are embedded in the HTML; no assets folder or installation is required.

Includes responsive layouts, light/dark mode, search and category filters, and a daily rotation of the three existing facts. History and Technology show an empty state until you add facts.

Validation: JavaScript syntax and HTML anchor/image references checked. Browser rendering was not tested.

Image source links are in the footer. Reuse licenses for the third-party photos have not been verified; check permissions or substitute photos you own before public use.
